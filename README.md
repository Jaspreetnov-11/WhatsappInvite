# Vivek & Bhavini — Wedding Invitation

Scroll-driven mobile wedding invitation (single `index.html`, no build step).

- Open `index.html` on any static host (GitHub Pages, Netlify, Vercel).
- Set `RSVP_WHATSAPP` at the top of the script to the RSVP number (country code, no `+`).
- Libraries load from CDN: GSAP + ScrollTrigger, Lenis, Google Fonts.
